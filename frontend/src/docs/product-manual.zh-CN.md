# 智枢文渊（ZhiShu）产品说明书

> 智枢数据库知识管理系统 —— 基于大语言模型（LLM）与 RAG（检索增强生成）技术的企业级知识管理与智能问答平台。

---

## 1. 产品简介

智枢文渊帮助企业把分散的文档、网页、问答沉淀为**可检索、可对话、可发布**的知识资产：

- **知识加工**：上传文档自动解析、分块、向量化，支持 FAQ、Wiki、数据源同步；
- **智能对话**：基于知识库的流式问答，答案附带**引用来源**，支持 Agent 多步推理与工具调用；
- **智能体发布**：把知识库与提示词封装成智能体，通过网页嵌入、IM 渠道、API 对外服务；
- **协作共享**：多空间、多角色协作，成员管理、知识共享与全程审计。

---

## 2. 快速上手

1. **登录系统**：使用管理员分配的账号登录（首次登录建议先完成页面上的新手引导）。
2. **确认模型已接入**：创建知识库前需要系统管理员先在「设置 → 模型管理」接入对话模型（KnowledgeQA）与 Embedding 模型。若您不是系统管理员且模型尚未接入，请联系系统管理员。
3. **创建知识库**：左侧导航 →「知识库」→「新建知识库」，选择类型（文档库 / FAQ 库）、填写名称并绑定模型。
4. **上传文档**：进入知识库详情，点击「上传文档」，支持本地文件、网页链接（URL）、手动录入与数据源同步四种方式。
5. **发起对话**：左侧导航 →「新对话」，`@` 引用知识库后提问，回答将附带知识来源引用。

## 3. 核心功能

### 3.1 知识库管理

| 功能 | 说明 |
| --- | --- |
| 双类型知识库 | 文档库（PDF/Word/Markdown 等）与 FAQ 问答库，创建后类型不可更改 |
| 文档入库 | 本地文件/文件夹、URL 抓取、手动录入、数据源同步（飞书、Notion、语雀等） |
| 解析与分块 | 解析进度可视化、分块在线编辑、版本历史与回滚、分块推荐问题 |
| 标签与文件夹 | 批量打标、文件夹树管理，多条件筛选 |
| Wiki 自动生成 | 队列驱动批量生成 Wiki 页面，支持目录树、版本 diff 与回滚 |

### 3.2 智能对话

- **RAG 快速问答**：流式回答，展示 RAG 流水线进度（检索 → 重排 → 生成）；
- **引用溯源**：每条回答标注知识来源，点击可查看原文出处，区分知识库与网络来源；
- **Agent 推理**：ReAct 多步循环可视化，工具调用支持人工审批卡与会话内 MCP OAuth 授权；
- **会话管理**：分组、置顶、搜索、批量管理，AI 自动生成会话标题；
- **记忆**：个人记忆与空间记忆双层，跨会话沉淀偏好与背景；
- **临时附件**：对话中临时上传图片/文档，异步解析后参与问答。

### 3.3 智能体与发布

- **智能体建模**：一站式编辑器配置模型、人设、提示词模板、开场白、知识库策略、工具与 MCP、审批策略；
- **嵌入渠道**：生成 iframe 嵌入代码挂到外部网站，访客免登录问答；
- **IM 渠道**：绑定企业微信、钉钉、飞书等 IM 平台，在聊天工具内直接问答；
- **API Key**：按能力范围（知识/自动化/协作）签发密钥，附 SSE 调试台。

### 3.4 协作共享

- **共享空间（组织）**：创建组织，通过邀请码/邮箱邀请成员，支持加入审批；
- **知识共享**：知识库、智能体可按组织共享，目标空间出现「共享给我」视图；共享不放大本地权限；
- **审计日志**：空间管理员可查看 `rbac.*` 动作审计，支持按动作/结果/操作人过滤。

### 3.5 个人偏好

设置中心支持语言、主题、字体字号调整与密码修改。

## 4. 角色与权限说明

系统采用「空间角色 + 平台系统管理员」双层权限模型。

### 4.1 角色一览

| 角色 | 定位 |
| --- | --- |
| 系统管理员（SystemAdmin） | 平台级管理者：模型接入、引擎与基础设施配置、任务队列、平台审计 |
| Owner（空间所有者） | 空间最高权限：成员管理、API Key 签发、知识共享 |
| Admin（空间管理员） | 空间日常管理：成员、共享、消息管理、提示词模板、配置只读 |
| Contributor（内容贡献者） | 上传文档、编辑分块、维护 FAQ 与 Wiki |
| Viewer（只读成员） | 检索、问答、阅读 Wiki |

### 4.2 权限矩阵

| 功能 | Viewer | Contributor | Admin / Owner | 系统管理员 |
| --- | :---: | :---: | :---: | :---: |
| 检索 / 对话 / 读 Wiki | ✅ | ✅ | ✅ | ✅ |
| 上传文档 / 编辑分块 / FAQ | — | ✅ | ✅ | ✅ |
| 成员与邀请、知识共享 | — | — | ✅ | ✅ |
| API Key 签发 | — | — | Owner | ✅ |
| 消息管理 / 长期记忆 / 提示词模板 | — | — | Admin+ | ✅ |
| 模型管理（添加/修改模型） | 只读 | 只读 | 只读 | ✅ 可写 |
| 向量库 / 存储 / 解析引擎 / 沙箱 / 网络搜索 / MCP | 只读 | 只读 | 只读 | ✅ 可写 |
| 检索配置等平台参数 | 只读 | 只读 | 只读 | ✅ 可写 |
| 知识库级选用（选模型 / 选向量库 / 选技能） | 只读 | — | ✅（不变） | ✅ |
| 平台运维（队列 / 平台 Key / 平台审计） | — | — | — | ✅ |

> **权限收口说明**：自 v2.9 起，「模型、向量库、存储后端、解析引擎、技能沙箱、网络搜索、MCP、检索配置」的**写权限**统一收归系统管理员；空间角色保留**只读**与知识库级「选用」能力。若您在设置中看不到「添加模型」按钮或保存报 403，说明该配置已由系统管理员统一管理，请联系系统管理员处理。

## 5. 常见问题

**Q：创建知识库时提示需要模型？**
创建文档库需要至少一个对话模型（KnowledgeQA）和一个 Embedding 模型；创建智能体只需对话模型。模型接入由系统管理员统一管理，请联系系统管理员在「设置 → 模型管理」完成接入。

**Q：上传文档后一直卡在解析中？**
解析由任务队列异步执行，可在知识库详情的解析时间线查看进度；长时间无进展请联系系统管理员在「平台管理 → 任务队列」排查失败原因并重试。

**Q：如何把知识库给外部网站用户使用？**
由空间管理员创建智能体并开通「嵌入渠道」，把生成的 iframe 代码挂到外部网站即可，访客免登录。

**Q：如何重新查看新手引导？**
点击左上角菜单顶部昵称旁的**帮助按钮**即可重新打开新手引导。
